## Key Design Decisions
- xcross for start marker, circle for end marker (directional reading: X → O)
- -4 level always dashed (speculative nature)
- Box used for zone fill (not plot fill) — supports dynamic per-setup lifecycle
- Superseded setups deleted entirely (no ghost lines)
- Status label positioned at -2σ price, moves rightward with bars
- Object budget allows 2 full concurrent setups + headroom for transitions
