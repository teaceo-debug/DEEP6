T9 Linkage Evidence — LabelStore
==================================
Date: 2026-05-21
File: deep6/sd_anchor/label_store.py

1. SCREENSHOT-TO-ANCHOR LINKAGE
   Every record in anchor_records has:
   - anchor_id (TEXT PRIMARY KEY) — unique UUID v4
   - screenshot_path (TEXT) — relative path from repo root to PNG
   One screenshot maps to exactly one anchor_id. No ambiguity.
   scan_orphans() detects records where screenshot_path is null or file missing.

2. DECISION-TIME IMMUTABILITY
   create_record() writes all Section 1.1 fields in a single INSERT.
   No UPDATE method exists for decision-time fields.
   Attempting to call create_record() with a duplicate anchor_id raises
   sqlite3.IntegrityError (PRIMARY KEY constraint).

3. HERMES VERDICT WRITE-ONCE
   write_hermes_verdict() checks hermes_verdict IS NULL before writing.
   Raises ImmutabilityError if already set. Cannot be overwritten.

4. OUTCOME WRITE-ONCE
   write_outcome() checks outcome_label IS NULL before writing.
   Raises ImmutabilityError if already set.
   outcome_label and outcome_resolved_at are NULL at create_record() time.
   No path allows outcome to be written at capture time.

5. HUMAN OVERRIDE ALWAYS MUTABLE
   write_human_override() has no write-once guard — matches schema spec
   for mutable fields.

6. QUERY METHODS
   query_pending_hermes() -> records WHERE hermes_verdict IS NULL
   query_pending_outcome() -> records WHERE outcome_label IS NULL OR 'pending'
   Both return full deserialized dicts — no ambiguity.

7. VALIDATION (schema Section 5)
   - UUID v4 format enforced
   - direction enum: bullish | bearish
   - pine_state enum: candidate | confirmed | active | invalidated | superseded
   - pine_confidence_score: 0-100 inclusive
   - anchor_high_price > anchor_low_price
   - range_val == anchor_high_price - anchor_low_price (computed check)
   - Level ordering: bullish (l4 < l2.5 < l2 < low), bearish (high < l2 < l2.5 < l4)
   - hermes_verdict enum: approve | veto | abstain
   - outcome_label enum: reached_minus2 | reached_minus2_5 | reached_minus4 |
     invalidated_before_target | pending

8. ATOMICITY
   All writes use sqlite3 transactions (autocommit off, explicit commit).
   WAL journal mode enabled for concurrent read safety.

9. SCHEMA MATCH
   All 24 fields from dataset-schema.md Sections 1.1-1.4 are present.
   Field named `range_val` in Python/SQL (avoids Python builtin `range`),
   maps to schema field `range`.
