# Futures Analytica Footprint Notes — 2026-04-24

Source basis:
- https://futuresanalytica.com/
- https://futuresanalytica.com/products/analyticachart4-1
- public Futures Analytica YouTube channel/video/short titles and thumbnails
- public product preview images

Observed recurring principles:
1. Dark, low-glare background with very selective accent colors.
2. Strong horizontal zones and reaction levels anchored across bars.
3. Dense numeric information, but not rainbow heatmap noise.
4. Event-first emphasis: imbalance, stacked imbalance, absorption, unfinished auction, reversal context.
5. Execution clarity: a trader should answer where price is, what side is aggressive, and whether that aggression is succeeding.

Actionable carryover for DEEP6:
- Location first, detail second.
- Cool-toned default data; reserve strong green/red/orange/yellow for events.
- Fade stale bars and low-priority numbers.
- Use persistent horizontal zones for memory and orientation.
- Make setup / trigger / response status obvious without forcing the trader to parse every cell.

Proposed DEEP6 concept directions:
- Institutional Minimal
- Zone-First Pro
- Signal-First Scalper
- Dense Analytica-Inspired
- Executive Hybrid
